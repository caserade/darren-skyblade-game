# SkyDrake checkpoint 10 visual gates

Actual concept and supplied model-sheet pixels were inspected. The concept is the design authority. Automated geometry checks support functional gates; they do not substitute for art approval.

| Gate | Status | Evidence / limitation |
|---|---|---|
| Planted ground gait and turning | Pass, sampled scope | Full/reduced, seven 60 Hz scenarios plus 30/120 Hz straight pursuit; 18 reports. Flat Gale Spires floor. |
| Stop, stagger, tail attack, takeoff transitions | Pass, sampled scope | Authored pose restoration, crouch easing; no sampled below-floor mesh in gait probes. |
| Flight / landing / repeated instances / fallback | Pass, sampled scope | 600-frame cycles, repeated encounter resource counts, 70 load/save checks. |
| Foot and haunch proportions | Improved / partial | Broader concept-led feet and haunches; matching four-angle renders. Further anatomy review needed. |
| Horn length and tail-arrow silhouette | Improved / partial | Shorter segmented horns; volumetric arrow now reads from side. Tail curve still differs from concept. |
| Blue / pale belly / cyan wings / gold horns | Retained | Original atlas retained; no duplicate vertex tint. Lighting affects apparent color. |
| Belly plates and scales | Open | Existing narrow bands / diffuse scale detail do not match broad clean concept plates. Texture experiment was rejected. |
| Wing curvature and folds | Improved / partial | Curved panels and raised tips, retained ribs; still stiff and geometric at some extremes. Rib ends overshoot some membrane points. |
| Dorsal spines | Open | Existing thin spines read edge-on from directly behind; the supplied concept has fuller cross-sections. |
| Extreme skin deformation | Open | Full worst attack edge ratio 8.430x (09: 9.518x); hit/death/turn improve. Fly 3.700→3.884, land 2.997→3.180, tailWhip 6.065→6.423. Some shoulder/hip pulling remains visible. |
| Neck / face / hand proportions | Partial | Existing candidate still differs from supplied concept; no final-match claim. |
| Death readability | Open limitation | Existing 16-tick removal window retained; 14 clips and native durations retained in assets. |
| Integrated cast / publication | Pending | Chomp and Stormbelly preserved; checkpoint 10 remains unpublished for combined review. |
